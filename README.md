# 30-Day Data Analytics Challenge

**Author:** Toluwalase  
**Institution:** Federal University of Technology Akure (FUTA) | WorldQuant University  
**Tool Stack:** SQL Server · Power BI  
**Domain Focus:** Sales & Finance  

---

## The Challenge

Every day for 30 days I pick an unconventional business or financial question,
dig through raw CSVs and internet data to find the answer, write the full 
analysis in SQL, build a Power BI dashboard, and post the findings on LinkedIn.

No fluff. Just data, analysis, and honest conclusions.
